# 🌍 WanderLust

WanderLust is a full-stack Airbnb-inspired travel and accommodation web application that allows users to explore unique stays, create and manage property listings, upload images, and share reviews.

The application is built using **Node.js, Express.js, MongoDB, Mongoose, and EJS**, following an **MVC architecture**. It includes secure user authentication, authorization, session management, image uploads, reviews, flash messages, validation, and interactive maps.

## ✨ Features

* 🔐 User Registration, Login & Logout
* 🏠 Create, Edit & Delete Property Listings
* 🖼️ Image Upload & Cloud Storage
* 🔍 Search and Explore Listings
* ⭐ Ratings & Review System
* 🗺️ Interactive Location Maps
* 👤 User Authentication & Authorization
* 💬 Flash Messages
* 🛡️ Input Validation & Error Handling
* 📱 Responsive User Interface
* 💾 MongoDB Atlas Database
* 🔒 Persistent Sessions using MongoDB

## 🏗️ Architecture

The project follows the **Model-View-Controller (MVC)** architecture to maintain a clean and scalable code structure.

```text
WanderLust
│
├── models/          # Database models
├── controllers/     # Application logic
├── routes/          # Express routes
├── views/           # EJS templates
├── public/          # CSS, JavaScript & static files
├── utils/           # Utility functions & error handling
├── middleware/      # Authentication & validation middleware
├── app.js           # Main application
└── package.json     # Dependencies & scripts
```

## 🎯 Project Objective

The goal of WanderLust is to build a real-world full-stack accommodation platform while implementing practical concepts such as **RESTful APIs, MVC architecture, authentication, authorization, CRUD operations, database management, cloud storage, session handling, and third-party API integration**.
